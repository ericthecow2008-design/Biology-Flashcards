# BIOL 130 flashcard kit (Modules 6–8)

This folder is a self-contained kit for making Eric's BIOL 130 flashcards for Modules 6–8: about 230 cards in four formats, including case studies.
Read `START_HERE.md` first and follow it phase by phase. Run every command from this folder.

- `STYLE_GUIDE.md` is Eric's standing brief for every card in the series.
- Never edit anything in `ref/` or `notes/`. Write your own files to `work/` and the deliverables to `outputs/`.
- Keep `work/PROGRESS.md` up to date, and commit and push after each phase, so a later session can resume.
